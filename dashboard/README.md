# Albert AI dashboard

React + TypeScript dashboard for live defense-loop monitoring, version evaluations, telemetry, database fleet hunting, and denied operations. Tailwind CSS v4 provides the stylesheet pipeline; charts require no additional package.

Use Node.js 22.12 or newer. Run all installation and verification in the project Codespace:

```sh
cd dashboard
npm install
npm run typecheck
npm run test
npm run build
npm run dev
```

Commit the lockfile generated by the remote installation. The development server binds to `0.0.0.0:5173` and proxies `/api` to `http://localhost:8787`, stripping the `/api` prefix. The Vite server reads `AGENTGUARD_API_KEY` from the repository root `.env` or process environment and injects a bearer authorization header into proxied requests. Keep this credential server-only; do not prefix it with `VITE_`. Run the backend on port 8787 in the same Codespace. Expose port 5173 through Codespaces; the browser does not need direct access to port 8787.

Metrics and denied operations refresh two seconds after each prior request finishes. Database fleet hunts run only when the refresh button is clicked; an optional agent ID narrows the query. Every new defense run clears prior run events and evaluations. SSE event IDs are deduplicated, terminal events close the stream, and version results replace prior totals. The activity panel retains the latest 300 events while continuing to deduplicate all event IDs for the current run.

Missing measurements display as pending or unavailable. Query statistics show the backend's actual `rowsRead` and `elapsedMs`. Model output, event payloads, and denied operations render as escaped text; only absolute HTTP(S) links are clickable.
